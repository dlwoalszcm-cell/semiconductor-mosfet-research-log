## 연구 일지

### 2026-11-05 · 처음으로 직접 짠 TCAD 측정 스크립트 (내 PC에서 실행)

- Windows PC에 DEVSIM 설치 후 JFET 코스 실행. 화면 출력 숨기기 코드가 Windows 콘솔에서 오류 → `common.py` 수정.
- **직접 작성:** [`mosfet-tcad/my_jfet.py`](mosfet-tcad/my_jfet.py) — 할 일을 주석으로 먼저 쓰고 한 줄씩 코드로 옮김.
  Vd = 50 mV에서 Vg를 내리며 드레인 전류와 열린 채널 두께(`dev.opening()`) 측정:

  | Vg (V) | Id (µA/µm) | 열린 채널 (µm) | 공식 a − h (µm) |
  |---|---|---|---|
  | −0.5 | 0.126 | 0.200 | 0.187 |
  | −1.0 | 0.082 | 0.130 | 0.118 |
  | −1.5 | 0.044 | 0.065 | 0.058 |
  | −2.0 | 0.008 | 0.000 | 0.000 |

- 정리한 개념
  - 핀치오프 전압 Vp = qN_D·a²/(2ε)는 공핍 폭 공식에 W = a를 넣은 것 = "접합 **총** 전압이 얼마면 막히나".
    접합 총 전압 = Vbi − Vg + V(x) 이므로 Vg_off = Vbi − Vp, Vd_sat = Vp − Vbi + Vg.
  - 채널은 저항이라 전압이 소스 0 → 드레인 Vd로 오름 → 게이트–채널 역바이어스가 드레인에서 최대 → 드레인 쪽이 먼저 막힘.
  - 예측 연습: a를 0.6 → 0.8 µm로 바꾸면 Vp × 16/9 = 5.22 V, Vg_off = −4.33 V.
- **현실과 다른 점:** 이동도를 400 cm²/Vs로 고정했지만 실제 1e16 실리콘 전자는 약 1,200 → 전류는 약 3배 작게 나옴.
  반면 Vg_off는 정전기(푸아송) 문제라 이동도와 무관 → **어떤 숫자가 어떤 가정에 기대는지** 구분해야 함.
  실제 I-V는 측정으로 얻고, TCAD는 측정에 맞춰 보정(calibration)한 뒤 예측에 씀.
